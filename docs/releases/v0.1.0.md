# TabBatch v0.1.0

First tagged release of TabBatch, an Android app for organizing a collection of browser tab
URLs and exporting them to a portable file.

## Highlights

- **Organize by domain** — deterministic registrable-domain ("eTLD+1") grouping, so
  `docs.example.com` and `example.com` group together.
- **Exact-duplicate detection** — duplicates are flagged, never silently deleted; you choose
  whether an export keeps or drops them.
- **Search & select** — filter by title/URL/domain, select whole groups or individual records.
- **Export** — PDF, CSV, JSON (versioned schema), and plain text, all generated on-device.
- **Import** — Android share sheet (`ACTION_SEND`/`ACTION_SEND_MULTIPLE`), manual paste, or
  `.txt`/`.csv`/TabBatch `.json` file import via the Storage Access Framework.
- **Local-first** — no account, no backend, no analytics/telemetry/ads, and no `INTERNET`
  permission requested. Everything runs on-device.

## Technical

- Kotlin, Jetpack Compose, Material 3.
- Android, compileSdk/targetSdk 35, minSdk 26.
- MIT licensed.
- GitHub Actions CI (unit tests, lint, debug build on every push/PR).
- Domain layer is pure Kotlin with no Android framework dependency, unit-tested on the plain JVM.

## Important limitation

TabBatch cannot read, list, or control the tabs currently open in Chrome for Android — there is
no public Android API for a third-party app to do that. This is a deliberate platform-aware
design choice, not a missing feature: TabBatch is built around the input paths Android genuinely
supports (share intent, manual paste, file import). See
[`docs/PLATFORM_LIMITATIONS.md`](../PLATFORM_LIMITATIONS.md) and
[`docs/ARCHITECTURE_DECISIONS.md`](../ARCHITECTURE_DECISIONS.md) (ADR-0001) for the full
rationale.

## Artifact

The APK attached to this release, `TabBatch-v0.1.0-unsigned.apk`, is an **unsigned release
build** (`app-release-unsigned.apk`), not a Play-Store-ready signed release. Android will refuse
to install an unsigned APK as-is; a maintainer must sign it (or generate a debug build) before
end users can install it. See the project README's "Build from source" section, or generate a
release keystore and configure `signingConfigs` in `app/build.gradle.kts` to produce a properly
signed release APK.
